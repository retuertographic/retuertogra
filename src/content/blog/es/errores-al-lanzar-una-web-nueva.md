Publicar la web nueva da una sensación de meta alcanzada, pero en realidad es el punto de partida. Muchos problemas aparecen justo en las primeras semanas: formularios que no llegan, páginas que Google deja de encontrar o una versión móvil que nadie revisó con calma. La buena noticia es que casi todos se pueden prevenir.

## Errores frecuentes al lanzar

- **No revisar los formularios de verdad.** Envía una solicitud de prueba desde cada formulario y comprueba que llega al correo correcto y no acaba en la carpeta de spam.
- **Olvidar las redirecciones.** Si las direcciones de la web antigua dejan de existir, quienes llegan desde Google o desde enlaces guardados encuentran un error.
- **Revisarla solo en el ordenador.** Buena parte de las visitas llega desde el móvil. La web tiene que ser [[responsive|responsive]] de verdad: menús, botones, tablas y formularios cómodos con el pulgar.
- **Publicar sin certificado [[SSL|ssl]] o con avisos de seguridad.** El navegador lo muestra y genera desconfianza.
- **Dejar textos de prueba o páginas vacías.** Un «próximamente» o un texto de relleno resta credibilidad.
- **No dar de alta la web en las herramientas de medición.** Si no mides desde el primer día, no podrás comparar.
- **Pensar que ya está terminada.** Una web necesita actualizaciones, revisiones y mejoras con el uso.

## Lista de comprobación del día del lanzamiento

1. Probar todos los formularios y botones de contacto, incluido el enlace a WhatsApp o al teléfono.
2. Revisar la web en al menos un móvil Android, un iPhone y un ordenador.
3. Comprobar que las direcciones antiguas más visitadas redirigen bien.
4. Confirmar que el candado de seguridad aparece en todas las páginas.
5. Verificar textos legales, datos de contacto y horarios.
6. Activar la medición de visitas y enviar el mapa del sitio a Google.

## Cómo saber si la web funciona

Más visitas no siempre significa mejores resultados. Elige pocos [[KPI|kpi]] relacionados con el objetivo de la web y revísalos cada mes:

| Indicador | Qué te dice |
| --- | --- |
| Solicitudes, reservas o ventas | Si la web cumple su objetivo principal |
| Visitas desde buscadores | Si el [[SEO|seo]] técnico y el contenido funcionan |
| Velocidad y [[Core Web Vitals|core-web-vitals]] | Si la experiencia de carga es buena, sobre todo en el móvil |
| Páginas más visitadas y salidas | Qué interesa y dónde se pierde la gente |

Compara cada mes con el anterior y, pasado un tiempo, con la misma época del año pasado: en zonas turísticas como Tenerife la temporada influye mucho en las cifras.

## Después del lanzamiento

Programa una revisión a las dos semanas y otra a los tres meses. Con los datos en la mano, decide qué páginas mejorar, qué contenidos añadir y qué funciones conviene incorporar en la siguiente fase.
