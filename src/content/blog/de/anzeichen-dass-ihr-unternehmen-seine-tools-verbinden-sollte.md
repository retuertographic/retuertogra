Die meisten kleinen Unternehmen arbeiten heute mit mehreren Tools: einem Formular auf der Website, einer Verwaltungssoftware, einer Tabelle für die interne Kontrolle, E-Mail und vielleicht einem [[CRM|crm]]. Jedes funktioniert für sich genommen gut. Das Problem entsteht dazwischen – wenn jemand von Hand übertragen muss, was in dem einen steht, um es in das andere einzugeben. Eine [[Integration|integracion]] verbindet diese Tools, damit Daten ohne Zutun von einem ins andere gelangen.

## Anzeichen, dass Sie es brauchen

Gehen Sie diese Liste durch. Wenn Ihnen mehrere Punkte bekannt vorkommen, gibt es Handarbeit, die sich vermeiden lässt:

1. **Sie kopieren täglich** Kundendaten, Bestellungen oder Anfragen von einer Anwendung in die andere.
2. **Dieselben Informationen liegen an mehreren Orten** und stimmen nie ganz überein.
3. **Eine Person ist unersetzlich**, weil nur sie weiß, wie die Daten von einem System ins andere kommen.
4. **Benachrichtigungen hängen vom Gedächtnis ab**: Man muss daran denken, eine E-Mail zu schicken, wenn eine Bestellung eingeht, oder eine Aufgabe anzulegen, wenn eine Anfrage kommt.
5. **Dieselben Fehler wiederholen sich**: eine falsch abgeschriebene Telefonnummer, eine Bestellung, die nie im Lager ankommt, oder ein Kunde, der dieselbe E-Mail zweimal erhält.
6. **Berichte kosten Stunden**, weil Daten erst aus mehreren Tools zusammengetragen werden müssen.

## Beispiele für Aufgaben, die sich verbinden lassen

Typische Fälle in kleinen Unternehmen:

- **Website-Formular → CRM und E-Mail**: Jede Anfrage legt ein Kontaktprofil an und benachrichtigt die zuständige Person.
- **Bestellungen → Tabelle**: Jeder Verkauf wird automatisch in der Kontrolltabelle erfasst.
- **Eingehende E-Mails → Aufgaben**: Bestimmte Nachrichten erzeugen eine Aufgabe für das Team.
- **Synchronisierte Kundendaten** zwischen CRM, ERP und anderen SaaS-Anwendungen, damit eine Änderung in einem System auch in den anderen ankommt.

Technisch beruhen diese Verbindungen auf der [[API|api]] des jeweiligen Tools oder auf [[Webhooks|webhook]], die Daten in dem Moment senden, in dem etwas geschieht. Sie müssen nicht verstehen, wie das im Inneren funktioniert – wohl aber wissen, was wann passieren soll.

## Was Sie durch Integration gewinnen

- **Zeit**: Wiederkehrende Aufgaben binden keine Stunden des Teams mehr.
- **Weniger Fehler**: Daten werden immer auf dieselbe Weise übertragen.
- **Schnellere Reaktion**: Benachrichtigungen erreichen sofort die Person, die handeln muss.
- **Ein einziger Datenstand**: Alle arbeiten mit denselben Informationen.

## Wann es sich nicht lohnt

Wird eine Aufgabe einmal im Monat erledigt und dauert fünf Minuten, rechnet sich eine Automatisierung wahrscheinlich nicht. Sinnvoll ist [[Automatisierung|automatizacion]] bei Abläufen, die sich häufig wiederholen, mehrere Personen betreffen oder bei denen ein Fehler teuer wird. Beginnen Sie mit der Aufgabe, die Sie die meiste Zeit oder die meisten Fehler kostet.
